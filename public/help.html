Timeline Storyteller の使い方

年表のデータを読み込み、見せ方を選び、注釈を付けて、場面ごとに語るストーリーに仕立てるツールです。画面上のボタン名は英語なので、この説明でも英語のまま示しています。

1. データを読み込む

最初に開く読み込みパネルから、年表のデータか、保存済みのストーリーを読み込みます。あとから別のデータを開くときは、左のパネルの Open ボタンで読み込みパネルを出します。

ボタン読み込めるもの
DEMO(Load timeline data)用意されたデモ用の年表データです。天文学的な時間にわたるものから、1日だけのものまであります。
JSONJSON 形式の年表データです。各イベントには少なくとも start_date が必要です。
CSVCSV 形式の年表データです。見出し行に少なくとも start_date の列が必要です。
DEMO(Load timeline story)デモ用のストーリーです。
ストーリーのファイル以前に保存したストーリー(.cdc 形式)です。

データを選ぶと、イベントの件数、期間、カテゴリの一覧が表示されます。カテゴリの色見本をクリックすると色を変えられます。Draw this timeline を押すと年表が描かれます。

データの項目

1行(1件)が1つのイベントです。JSON でも CSV でも項目は同じです。

項目必須内容
start_date必須開始日です。YYYY、YYYY-MM、YYYY-MM-DD、YYYY-MM-DD HH:MM の形式で書きます。紀元前は -27 のように負の数で書けます。
end_date任意終了日です。start_date と同じ形式で書きます。省略すると、ある一時点の出来事になります。
content_text任意イベントの説明文です。注釈のラベルとして表示されます。
category任意イベントの分類です。色分けに使われます。
facet任意もう1つの分類です。複数の年表に分けて並べるときに使われます。category と同じ値でもかまいません。

CSV の例です。

start_date,end_date,content_text,facet,category
1868-10-23,1912-07-30,明治,元号,元号
1923-09-01,,関東大震災,出来事,災害

JSON の例です。

[
  {
    "start_date": "1868-10-23",
    "end_date": "1912-07-30",
    "content_text": "明治",
    "facet": "元号",
    "category": "元号"
  }
]

2. 見せ方を選ぶ

画面上部のパネルで、年表の表現(Timeline representation)、スケール(Scale)、レイアウト(Layout)を選びます。3つの組み合わせで年表の形が決まります。使えない組み合わせもあり、その場合はボタンが薄く表示されます。ボタンにマウスを乗せると、その選択肢の説明が出ます。

表現(Timeline representation)

Linear左から右へ読む、最もなじみのある年表の形です。
Radial円形に並べます。周期的なパターンを見せるのに向いています。全体が正方形に収まる利点もあります。
Spiralらせん状に並べます。出来事の並びをコンパクトに、遊び心をもって見せられます。全体が正方形に収まります。Sequential スケールでだけ使えます。
Curve自分で描いた曲線に沿って出来事を並べます。Sequential スケールと Unified レイアウトでだけ使えます。キャンバス上をドラッグして曲線を描き、ダブルクリックで描き直します。
Calendar月・週・日のカレンダーです。Chronological スケールと Segmented レイアウトで使えます。数十年以上にわたる年表には対応していません。
Grid10×10 のマス目です。Chronological スケールと Segmented レイアウトで使えます。数十年から数世紀にわたる年表に向いています。

スケール(Scale)

Chronological2017年、1999-12-31、午後6時37分のような、実際の日付や時刻を示すのに向いています。
RelativeFaceted レイアウトの複数の年表を、共通の起点「ゼロ」にそろえて比べるのに向いています。たとえば1940年から2010年まで生きた人物と、1720年から1790年まで生きた人物を並べると、どちらも0年から70年の目盛りで比べられます。
Log10を底とする対数の目盛りです。長い期間にわたり、出来事の分布が偏っている年表に向いています。Linear 表現で使えます。
Sequential出来事の順序と数だけを示します。
CollapsedSequential と Chronological の中間です。出来事の分布が不均等な年表に向いています。出来事と出来事の間隔を棒の長さで表します。Linear 表現と Unified レイアウトで使えます。

レイアウト(Layout)

Unified途切れのない1本の年表です。データに facet がないときに向いています。
Facetedfacet ごとに年表を分けて並べます。複数の年表を比べたいときに向いています。
Segmented年表を世紀や日のような意味のある区切りに分けます。区切りの単位は年表の期間に応じて決まります。Chronological スケールで使え、周期性のような、区切りごとのパターンや違いを見せるのに向いています。

3. 注釈を付け、絞り込む

左のパネルには、年表に文字や画像の注釈を加える操作、イベントを強調したり絞り込んだりする操作、年表やストーリーを書き出す操作がまとまっています。

  • イベントのラベル:イベントをクリックすると、content_text の内容がラベルとして付きます。ラベルは大きさと位置を変えられます。SHIFT キーを押しながらクリックすると、ラベルを出さずに強調だけできます。
  • キャプション(Annotate の引用符のボタン):自由な文章をキャンバスに置けます。大きさと位置を変えられます。
  • 画像(Annotate の画像のボタン):画像をキャンバスに置けます。大きさと位置を変えられます。
  • CLEAR:ラベル、キャプション、画像をまとめて消します。
  • Filter:カテゴリ、facet、区切り(segment)でイベントを絞り込みます。条件に合うイベントを目立たせる Emphasize と、合わないイベントを隠す Hide を選べます。

4. シーンを記録してストーリーにする

画面下部の赤い丸のボタンを押すと、いまのキャンバス(年表、ラベル、注釈)が、ストーリーの1つのシーンとして記録されます。見せ方や注釈を変えながら記録を重ねると、ストーリーになります。記録したシーンは下部のパネルに小さな画像で並びます。

ストーリーを再生する

  • 下部の四角い枠のボタンで、再生モードに入ります。もう一度押すと再生モードを抜け、編集用のパネルが戻ります。
  • シーンの小さな画像をクリックすると、そのシーンに移ります。
  • 右向きの矢印で次のシーンへ、左向きの矢印で前のシーンへ移ります。

5. 書き出す

左のパネルの Export を押すと、書き出しの選択肢が出ます。

PNGいまのキャンバスを画像として保存します。
SVGいまのキャンバスを、あとから編集できるベクター画像として保存します。
GIF記録したシーンを順に見せるアニメーション画像として保存します。
ストーリー記録したシーンとデータをまとめたファイル(.cdc 形式)として保存します。読み込みパネルから読み込むと、続きを編集できます。
